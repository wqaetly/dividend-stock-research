# 红利选股研究 · dividend-stock-research

一个中文 AI skill：先核查企业与分红可持续性，再用情景股息率筛选候选、推算参考买价，并明确组合约束。

基于 [dividend-yield-analysis](https://github.com/a985987819/dividend-yield-analysis) 的研究思路重写和修正。它是研究辅助工具，不承诺收益，不自动交易；没有实盘或回测业绩。上游来源及许可见 [UPSTREAM.md](UPSTREAM.md)。

## 使用

将整个仓库目录作为一个 skill 放进支持 `SKILL.md` 的 Agent 技能目录，目录名保留为 `dividend-stock-research`。例如 Codex 默认个人技能目录为 `~/.codex/skills`；自定义 `CODEX_HOME` 时使用其 `skills` 子目录。重新打开会话后调用：

```text
使用 $dividend-stock-research 比较伊利股份与双汇发展的分红可持续性。
按最新公开资料，分别用 4%、5%、6% 的税前股息率分析参考买价。
给出悲观、基准、较好情景，列出不支持买入的证据和原始公告来源。
```

这里的公司名称仅展示提问方式，不构成推荐或预设白名单。也可以请求：

```text
使用 $dividend-stock-research，从当前中证红利指数成分中初筛候选。
先说明能够覆盖多少家公司，再核查分红、资本支出和债务风险。
不满足条件可以没有候选，不要只按股息率排序。
```

需要 Agent 能搜索/读取最新财报。Python 3.10+ 是可选的算术校验工具，只有标准库依赖；没有 Python 也可以按公式用可靠计算工具核算。默认直接输出分析，不强制生成 HTML。

### 数据工具

默认优先调用宿主中已配置的 **Tushare MCP（`tushareMcp`）**，获取分红、财报、股本、价格和候选池数据；使用 Codex / ChatGPT 可用的内置联网工具查阅原始公告。具体接口与失败后的处理见 [数据工具选择](SKILL.md#数据工具选择)。

`agents/openai.yaml` 声明了 MCP 依赖，但安装 skill 不会自动配置服务、导入凭证或开通数据权限。工具列表可见也不代表每个接口均有权限，须实际查询确认。公告接口不可用时，可用内置联网查找公司、交易所或巨潮原文，不必额外接入自建搜索。Tushare 不可用时明确缺口并用公开披露补充；关键输入不齐时只给待核实结论。仓库不保存个人 Token 或带凭证的连接地址。

## 相比上游的主要修正

| 问题 | 本项目处理 |
|---|---|
| 经营现金流替换利润并乘固定70% | 禁止换基数；利润与政策估计派息，现金流、资本支出和债务验证支付能力 |
| 固定上年利润和悲观系数 | 纳入最新经营变化，分开设盈利、支付率及保守系数，解释正常化依据 |
| 高净现比或 ROIC 超过资本成本即认为分红可持续 | 作为辅助证据；不跨行业机械套用，金融企业单独处理 |
| 股息参考价直接等于低估/买入 | 输出满足特定假设的价格，买入量另看组合、期限和风险承受能力 |
| 研究过程容易变成只找支持证据 | 保留被排除对象、证据缺口、反对理由和结论失效条件 |

## 计算与验证

```text
情景每股分红 = 正常化每股收益 × 利润支付率 × 保守系数
参考买价 = 情景每股分红 / 要求的股息率
```

从仓库目录运行以下虚构算例（比例均用小数）：

```bash
python scripts/dividend_price.py --eps 2 --payout 0.6 --haircut 0.8 --required-yield 0.04 --price 20
python -m unittest discover -s tests -v
```

该算例得出每股分红0.96、参考买价24、按20元买价计算的情景税前股息率4.8%。脚本不联网、不读账户、不下单；不接受亏损盈利或超过100%的支付率进入普通分红模型。特殊分配需要单独分析。

测试覆盖公式、总量/每股一致性、保守性方向、停派情景及非法输入；这些检查不验证预测是否会实现，也不代表策略已回测。
